ERROR PREVENTION PATTERN
================================================================================

Pattern applied to EVERY .map() in React code:

   ✅ ALWAYS DO THIS:
   {Array.isArray(data) ? (
     data.map((item, idx) => (
       // render item
     ))
   ) : (
     // fallback UI or error message
   )}

   ❌ NEVER DO THIS:
   {data.map((item, idx) => (
     // Could crash if data is not array
   ))}

KEY RULE: Never assume external API data is always the expected type.
Always validate before using.
