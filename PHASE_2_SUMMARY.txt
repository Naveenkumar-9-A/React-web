PRICING ALGORITHM:

```javascript
const getEstimatedPrice = () => {
  const diff = destination.difficulty?.toLowerCase() || 'easy';
  const prices = {
    'easy': 1000,
    'moderate': 1500,
    'difficult': 2500,
    'very difficult': 4000
  };
  return Math.max(prices[diff] || 1000, 1000); // Minimum ₹1000
};
```

PRICING EXAMPLES:

Difficulty Level → Price
├─ Easy → ₹1000+
├─ Moderate → ₹1500+
├─ Difficult → ₹2500+
├─ Very Difficult → ₹4000+
└─ Undefined/Default → ₹1000+ (minimum)
