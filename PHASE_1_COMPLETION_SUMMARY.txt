KEY IMPLEMENTATION DETAILS
================================================================================

ROUTING:
  /treks/:id              → CardDetails (fetches from database)
  /destination/:slug      → CardDetails (reads from location.state)

DATA SOURCE DETECTION:
  if (location.state?.destination) {
    setSource('osm');
    setTrek(location.state.destination);
  } else {
    // Fetch from database
  }

NAVIGATION STATE PASSING:
  navigate(`/destination/${slug}`, {
    state: {
      source: 'osm',
      destination: osmData
    }
  });

CONDITIONAL RENDERING:
  - Hero background: gradient for OSM, image for database
  - Operators section: only for database treks
  - Famous Places/Nearby Attractions: maps correct field based on source
  - Trip Info: different fields based on source
  - Related Treks: hidden for OSM (empty array)

SAFE FALLBACKS:
  - trek.description || trek.summary || placeholder
  - trek.price_start && <show price> (only if exists)
  - trek.state && <show state> (only if exists)
  - Missing arrays show "Coming soon..."
