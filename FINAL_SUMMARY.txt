                        SEARCH FLOW OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

User Input (e.g., "Kerala")
           ↓
Search Trek Database
           ├─ Found? → Display trek in dropdown (🏔️)
           │
           └─ Not Found? → Search OpenStreetMap
                           ├─ Found? → Display OSM result (📍)
                           │
                           └─ Not Found? → "No results"

User Clicks Result
           ↓
Check Type
   ├─ Trek → Navigate to /treks/{id}
   │         → CardDetails page
   │
   └─ OSM → Navigate to /destination/{slug}
            → DestinationDetails page
            → Enriched content displayed

  rm -r node_modules

ISSUE: API returns 404
SOLUTION:
  Verify backend running: http://127.0.0.1:8000
  Check Django server logs
  Ensure database is migrated

ISSUE: Search returns no results
SOLUTION:
  Check if input is 2+ characters
  Verify Trek database has data
  Check Nominatim API availability

ISSUE: Enrichment not working
SOLUTION:
  Check OpenAI API key in .env
  Fallback enrichment should still work
  Check console for error messages

ISSUE: DestinationDetails page shows error
SOLUTION:
  Clear browser cache
  Check slug format (lowercase, hyphenated)
  Verify backend /api/enrich-destination/ endpoint
  Check network tab for API response
